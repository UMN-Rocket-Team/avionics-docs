# GYRO Testing

This guide walks through setting up and testing GYRO. If you're confused about any step, please ask the Firmware lead.

## Download the GitHub Actions Build Artifact

Go to the [GYRO repo](https://github.com/UMN-Rocket-Team/GYRO) on GitHub and click on **Actions**.

If you recently pushed changes to `build/GNCv1.0` and the generated files in `Firmware/AutoGenerated` were updated, the build workflow should run automatically.

Otherwise, you can manually trigger the workflow for `main` or any other branch:

1. Select the build workflow under **Actions**
2. Click **Run workflow**
3. Select the correct branch from the dropdown menu
4. Click **Run workflow** to start the build
5. Wait for the workflow to finish and verify that it completed successfully, indicated by a green checkmark

{: .note }
Make sure the workflow ran on the correct branch and that you're using the most recent successful build for that branch.

If the workflow fails or no build is available, contact the Firmware lead.

### Download the Build

1. Click on the successfully completed workflow run
2. Scroll down to **Artifacts**
3. Download `GYRO-firmware`
4. Extract the downloaded ZIP file. It should contain `GYRO.elf`

## Required Software

Before testing, make sure you have the following software installed:

1. [CoolTerm](/docs/tutorials/firmware/resources/coolterm/)
2. [STM32CubeProgrammer](https://www.st.com/en/development-tools/stm32cubeprog.html#st-get-software)

## Board Setup

Connect the ST-LINK to the pads labeled `STLink1` on the board, with the smiley face facing up.

### Battery and Switch Configuration

GYRO uses two 7.4 V (2S) LiPo batteries to power the board and its components. Each battery has a separate power connection:

The board has two battery terminals:

- **Battery 1:** Powers the board and all components except the servos
- **Battery 2:** Powers the servos

Each battery has a corresponding screw switch:

- **SW1:** Controls power from Battery 1
- **SW2:** Controls power from Battery 2

The screw switches allow you to control whether the board and its components receive power when the batteries are connected.

**If you're not using the servos**, set up the board as follows:

- Battery 1 has a battery connector attached
- SW1 is connected and screwed in
- Battery 2 is not connected

**If you're using the servos**, set up the board as follows:

- Both battery terminals have battery connectors attached
- SW1 and SW2 are connected and screwed in
- Servos are connected to PWM1 and PWM3

### Check Battery Voltage

Before connecting the batteries to the board, make sure they're sufficiently charged.

1. Set your multimeter to DC voltage (V)
2. Connect the red probe to the battery's positive terminal (red wire)
3. Connect the black probe to the battery's negative terminal (black wire)
4. Verify that the voltage above **7.4 V**

{: .note }
The batteries should not be below 7.4 V. If a battery measures below 7.4 V, use the battery charger before testing.

### Connect the Batteries

Connect the batteries to the connectors attached to Battery 1 and Battery 2 (if needed).

{: .important }
Always connect and disconnect batteries using the **battery connectors**, NOT the screw terminals on the board!

## STM32CubeProgrammer Setup

1. Connect the ST-LINK to your computer (if you haven't already)
2. Open STM32CubeProgrammer
3. Leave the settings at their default values
4. Click **Connect**

{: .note }
If you receive the error `No debug probe detected`, STM32CubeProgrammer cannot detect the ST-LINK. Check that the ST-LINK is properly connected to your computer. Also, check that Battery 1 is plugged in.

## Programming the Board

Once the board is set up, return to STM32CubeProgrammer.

1. Navigate to **Erasing & Programming**
2. Under **File path**, click **Browse**
3. Navigate to the extracted GitHub Actions build artifact and select `GYRO.elf`
4. Make sure **Verify programming** and **Run after programming** are checked
5. Click **Start Programming**

After programming, verify the following:

- STM32CubeProgrammer indicates that programming completed successfully
- The board produces a sound during startup
- Both servos perform a calibration sweep if Battery 2 is connected
- The board's startup flashing sequence stops

### Verify Driver Initialization

1. Open CoolTerm and connect to the correct serial port (if you haven't already)
2. Verify that output from GYRO appears in the terminal
3. Check that all required drivers initialized successfully

If any drivers fail to initialize, report the issue to the Firmware lead.

### Start Testing

The testing environment is now ready!

Type `help` into CoolTerm to view the available commands.

## After Testing

1. Disconnect the batteries from their **connectors**, not the battery terminals
2. Disconnect the ST-LINK
3. Put all equipment back where it belongs
4. Report any failed driver initializations or unexpected behavior to the Firmware lead
