# Resources

This page contains useful resources, guides, and general guidelines for the Firmware team. You'll find information on setting up your development environment, testing and debugging firmware, using Git and GitHub, and other things you might need while working on firmware.

If you think there's a resource missing or something that should be added or updated, feel free to reach out to the Firmware lead!
