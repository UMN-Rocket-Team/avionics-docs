# Projects

covering architecture, design considerations, and how hardware, firmware, and GNC come together
for that build.

Click into a project below for full details.

## Adding a new project

1. Duplicate `project-template.md` inside `docs/projects/` and rename it (e.g. `docs/projects/name.md`).
2. Update its front matter: `title`, `nav_order` (controls ordering in the list below and in the sidebar).
3. Fill in the sections and delete the instructional comments.
